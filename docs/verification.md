## Windows 中文成品路径修复

复现：yt-dlp 默认编码输出的中文 AF_PATH 被 Node UTF-8 解码为乱码，成品已落盘但 ffprobe 使用乱码路径失败。所有 yt-dlp 调用显式传入 --encoding utf-8。用 BV1Xwt663E2Z 已有成品复测：路径正确，1920x1080 校验通过，文件大小和 mtime 未改变。21 项测试通过。初始提示改为获取视频信息，已有文件提示改为校验本地文件。
